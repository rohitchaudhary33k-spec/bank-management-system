# Bank Management System

A simple Java-based Bank Management System that allows users to create and manage bank accounts.

## Features

- Create a new account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- View all accounts
- Delete an account

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- Exception Handling

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac BankManagement.java
